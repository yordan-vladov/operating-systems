# Търсене на файлове

---
## Съдържание

- Търсене на файлове по име
- Търсене във файловата йерархия
- Работа с намерени
---
## locate

- Позволява ни да търсим файлове по име
```bash
locate bin/zip
locate zip | grep bin
```
---
## find

- Позволява ни да търсим съдържанието на дадена папка
```bash
find ~ # намира всички в нашата home директория
```
---
## find -type

- Връща само ресурси от определен тип
```bash
find ~ -type d # връща само директории
find ~ -type f # връща само файлове
```
---

| Тип | Описание           |
| --- | ------------------ |
| b   | Блоково устройство |
| c   | Символен файл      |
| d   | Директория         |

---

| Тип | Описание       |
| --- | -------------- |
| f   | Обикновен файл |
| l   | Символен линк  |

## find -name

- Позволява ни да търсим файлове, чийто имена спазват определен шаблон
```bash
find ~ -type f -name "*.txt"
```
---
## find -name - Шаблони

- `-name` използва същите шаблони като shell-а (`*`, `?`, `[]`), а **не** регулярни изрази
- Шаблонът винаги се огражда в **кавички** — иначе shell-ът ще го замени преди `find` да го види
- `-name` сравнява **цялото** име на файла
- `-iname` - същото, но без разлика между малки и главни букви
```bash
find ~ -name "*project*" # съдържа project
find ~ -name "data*" # започва с data
find ~ -name "*.conf" # завършва на .conf
find ~ -name "*.???" # разширение от точно 3 символа
find ~ -iname "*.JPG" # .jpg, .JPG, .Jpg, ...
```
---
## find -regex

- Ако ни трябва регулярен израз, използваме `-regex`
- Изразът трябва да съвпада с **целия път**, а не само с името
- `-regextype posix-extended` - разширени регулярни изрази
```bash
find ~ -regextype posix-extended -regex ".*/[a-z]+[0-9]\.txt" # напр. note1.txt
```
---
## Броене на резултатите

- `find` извежда по един резултат на ред, затова можем да ги преброим с `wc -l`
- `2> /dev/null` скрива грешките за директории, до които нямаме достъп
```bash
find ~ -type f -name "*.txt" | wc -l
find / -type d -name "*log*" 2> /dev/null | wc -l
```

## find -size

```bash
find ~ -type f -size +1M # повече от 1 MB
find ~ -type f -size -1k # по-малко от 1 kB
```

| ------ | --------------- |

| Символ | Единица  |
| ------ | -------- |
| k      | килобайт |
| М      | мегабайт |
| G      | гигабайт |

## Времена на файл

- Всеки файл пази три времена:
    - **mtime** (*modify*) - последна промяна на **съдържанието**
    - **ctime** (*change*) - последна промяна на **метаданните** (права, собственик, име) или на съдържанието
    - **atime** (*access*) - последно четене
- Вижда се с `stat file.txt`

---
## find -mmin n и -mtime n

- `-mmin n` - съдържанието е променено преди *n* **минути**
- `-mtime n` - съдържанието е променено преди *n* **дни** (24-часови периода)
- `+n` - преди повече от *n*; `-n` - преди по-малко от *n*; `n` - точно *n*
```bash
find ~ -mmin -5 # променени през последните 5 минути
find ~ -mtime -2 # променени през последните 2 дни
find ~ -mtime +30 # непроменяни повече от 30 дни
```

---
## find -cmin n и -ctime n

- Същото като `-mmin` и `-mtime`, но за **ctime** - хваща и промени по правата, собственика и т.н.
```bash
find ~ -cmin -5 # с променено съдържание или метаданни през последните 5 минути
find ~ -ctime -2 # с променено съдържание или метаданни през последните 2 дни
```

---
## find -newer file

- `-newer file` - съдържанието е променено **по-скоро** от съдържанието на *file*
- `-cnewer file` - същото, но сравнява **ctime**
- `-newermt дата` - променени след определена дата
```bash
find ~ -newer test.txt # променени след test.txt
find ~ -newermt "2026-11-01" # променени след 1 ноември 2026
find ~ -newermt "7 days ago" # променени през последните 7 дни
```

## Оператори

- Позволяват ни да комбинираме няколко условия при търсенето:
    - **-and**: Връщаме ресурси, които спазват всички зададени условия
    - **-or**: Връщаме ресурси, които спазват поне едно от зададените условия
---
- **-not**: Връщаме ресурси, които не спазват зададеното условие
- **()**: Позволяват ни да групираме условия
---
```bash
find ~ -mtime -7 -and -user john # всички ресурси на john, които са променяни в последните 7 дена
find ~ -name "*.txt" -or -name "*.log" # всички .txt и .log файлове
find ~ -not -user john # всички файлове, които не са на john
find ~ \( -name "*.txt" -and -user john \) -or -name "*.log"
# всички .log файлове ИЛИ всички .txt файлове на john
```
---
## Действия

- Позволяват ни да направим нещо с намерените ресурси:
    - **-delete** - трие съответстващите файлове
    - **-ls** - дава детайли за намерените файлове
    - **-print** - принтира файлът/директория (default)
    - **-quit** - спира търсенето, след като е направено съотвествие
---
```bash
find ~ -type f -empty -delete # трие празни файлове
find ~ -type f -name "*.sh" -ls # извежда информация за всички shell скриптове
find ~ -type f -size +100M -print -quit # намира файл по-голям от 100 MB и спира
```

## -exec

- Изпълнява команда за всеки намерен файл
- `{}` се заменя с пътя до файла
- `\;` - командата се изпълнява **веднъж за всеки** файл
- `+` - всички файлове се подават наведнъж на **една** команда (по-бързо)
```bash
find ~ -name "*.tmp" -exec rm {} \; # изтрива всеки .tmp файл
find ~ -name "*.sh" -exec ls -l {} + # подробна информация за всички .sh файлове
find ~ -name "*.txt" -exec cp {} ~/backup/ \; # копира всички .txt файлове в ~/backup
```

---
## -printf

- Извежда информация за файла в избран от нас формат

| Символ | Значение                  |
| ------ | ------------------------- |
| `%p`   | пълен път                 |
| `%f`   | само името                |
| `%s`   | размер в байтове          |
| `%t`   | дата на последна промяна  |
| `\n`   | нов ред                   |

```bash
find ~ -type f -printf "%s %p\n" # размер и път на всеки файл
```

## Пример - Най-големите файлове

- Комбинираме `find` със `sort` и `head`/`tail`
```bash
# Петте най-големи .log файла (размер в байтове и път)
find ~ -type f -name "*.log" -printf "%s %p\n" | sort -nr | head -n 5

# Най-малкият .csv файл, с подробна информация (7-мата колона на -ls е размерът)
find ~ -type f -name "*.csv" -ls | sort -n -k 7 | head -n 1
```

---
## Пълен път

- `find` извежда пътищата спрямо началната директория, която сме подали
- Ако тя е абсолютен път (`~`, `/home/user`), и резултатите са с абсолютен път
```bash
cd ~
find . -name "*.log" # ./logs/app.log
find ~ -name "*.log" # /home/user/logs/app.log
find "$PWD" -name "*.log" # /home/user/logs/app.log
```

## xargs

- Позволява ни подадем намерените файлове/директории като аргумент на команда
---
```bash
find ~ -name "*.txt" | xargs cat # принтира всичките текстови файлове
find ~ -name "*.txt" | xargs wc -l # принтира броят редове всичките текстови файлове
find ~ -name "*.sh" | xargs chmod +x
```
---
## xargs -I

- По подразбиране `xargs` слага аргументите **в края** на командата
- С `-I {}` избираме къде да бъдат поставени
```bash
find ~ -name "*.py" | xargs -I {} cp {} ~/backup/ # копира всеки .py файл в ~/backup
```
- **Внимание:** `xargs` разделя по интервали — файлове с интервали в името се объркват. В такъв случай използваме `find ... -print0 | xargs -0 ...` или `-exec`
---
## Опции

- Определят обхвата на търсенето
- **-maxdepth levels** - максималната дълбочина на търсенето
- **-mindepth levels** - минималната дълбочина на търсенето
---
```bash
find ~ -maxdepth 1 # търси само в текущата директория и в нейните преки "деца"
find ~ -maxdepth 2 # търси до "внуците" включително
find ~ -mindepth 2 # пропуска текущата директория и преките ѝ "деца" - търси от "внуците" надолу
```
