# Работа с данни

---
## Всичко е файл

- Философия за дизайна на Linux операционната система
- Всички системни ресурси, се третират като файлове, включително:
    - файлове и директории
    - устройства
    - процеси
---
## Програми

- Пазят се като изпълними файлове
- `/bin` - основни системни команди (cat, mv, ...)
- `/usr/bin` - незадължителни потребителски команди (g++, mysql, vscode)
- В модерни системи директориите често изпълняват една и съща цел
---
## Устройства

- Устройства като дискове, клавиатури и мишки се третират като специални файлове, които се пазят в папката `\dev`
- `\dev\sda` - дискът
- `\dev\ttyS0` - първият сериен порт
- `\dev\usb` - съдържа usb устройства
---
## Процеси

- Процесите се пазят като файлове в директорията `/proc/`
- Всеки процес получава директория (напр. процес с PID 1234 получава директория `/proc/1234`)
---
## Конфигурация

- Системните настройки се пазят в файлове
- `/etc` - пази конфигурацията за системата
- `/sys` - пази конфигурацията за ядрото
---
# Команди за работа с данни
---
## cat

- Показва съдържанието на файл

```bash
cat /etc/passwd
```
---
## head

- Показва началото на файл (По подразбиране първите 10 реда)

```bash
head /etc/passwd
```
---
## head -n

- Позволява ни да поясним колко редове искаме да видим

```bash
head -n 7 /etc/passwd # първите 7 реда
head -n -7 /etc/passwd # премахва последните 7 реда
```
---
## head -c

- Показва първите байтове на файл

```bash
head -c 7 /etc/passwd # първите 7 байта
```
---
## tail

- Показва краят на файл (По подразбиране последните 10 реда)

```bash
tail /etc/passwd
```
---
## tail -n

- Позволява ни да поясним колко редове искаме да видим

```bash
tail -n 7 /etc/passwd # последните 7 реда
tail -n +7 /etc/passwd # От 7-ят ред до края
```
---
## Пайпове - "|"

- Позволява ни да комбинираме команди
- Взима изходът на една команда и го превръща във вход на друга команда

```bash
command1 | command2 | command3 | ...
```
---
## Пайп - Пример

- Искаме да принтираме 5-ят до 10-ят ред на "/etc/passwd"

```bash
head -n 10 /etc/passwd | tail -n 5
```

- `tail` **не** получава име на файл — чете от stdin, т.е. от изхода на `head`
- Ако напишем `tail -n 5 /etc/passwd`, `tail` ще игнорира пайпа и ще прочете целия файл
---
## sort

- Позволява ни сортираме съдържание на стандартният вход **или** на подаден файл или файлове
---
```bash
sort /etc/passwd
cat /etc/passwd | sort
```
---
## sort - Опции

- "-n" - сортираме числово
- "-r" - сортираме в низходящ ред
- "-k" - сортираме по ключ
- "-t" - определяме разделител
- "-u" - премахва повтарящите се редове
---
## sort - Примери

```bash
# Сортира числата от numbers.txt числово (1, 38, 45, 123, 2000).
# Без -n сортирането е текстово и "123" би било преди "38".
sort -n numbers.txt

# Сортира числово, но в низходящ ред (2000, 123, 45, 38, 1)
sort -rn numbers.txt

# Сортира изхода на "ls -l" по 8-мата колона (час/година на последна промяна).
# Колоните са разделени с интервали: права, връзки, собственик, група,
# размер, месец, ден, час/година, име
ls -l | sort -k 8

# Сортира файловете по размер (5-тата колона), числово
ls -l | sort -nk 5

# Колоните в /etc/passwd са разделени с ":", затова задаваме разделител с -t.
# Сортираме числово по 4-тата колона (GID - номер на основната група)
cat /etc/passwd | sort -t ":" -nk 4
```
---
## sort -k - Начало и край на ключа

- `-k 2` означава „от 2-рата колона **до края на реда**“
- `-k 2,2` означава „**само** 2-рата колона“
- При текстово сортиране разликата има значение, затова е добре винаги да задаваме и края

```bash
# Сортира само по 2-рата колона (име), разделител ";"
sort -t ";" -k 2,2 data.info

# Сортира числово по 3-тата колона, в низходящ ред
sort -t ";" -k 3,3 -nr data.info
```
---
## sort - Десетични числа

- `sort -n` разпознава десетичния разделител според **езиковите настройки** (locale) на системата
- При български настройки (`bg_BG`) десетичният разделител е **запетая**, затова `2.5` се чете като `2`
- Проверка: `locale | grep LC_NUMERIC`
- Решение — задаваме „неутрален“ locale само за командата:

```bash
LC_ALL=C sort -t ";" -k 3,3 -n books.info
```
---
## Пример - Комбиниране на команди

- Файл `books.info` във формат `КНИГА;БРОЙ;ЦЕНА`:

```txt
Тютюн;12;18.5
Бай Ганьо;30;9.9
Под игото;25;14.2
Железният светилник;8;16.0
```

```bash
# Само заглавията, по азбучен ред
cut -d ";" -f 1 books.info | sort

# Заглавието на най-скъпата книга, записано във файл
sort -t ";" -k 3,3 -nr books.info | head -n 1 | cut -d ";" -f 1 > most_expensive

# Последните 2 реда от файла, сортирани по брой
tail -n 2 books.info | sort -t ";" -k 2,2 -n
```

- Редът на командите има значение: `tail | sort` взима последните редове **от файла** и тогава ги сортира, а `sort | tail` взима последните редове **след** сортирането
---
## uniq

- Премахва повтарящите се последователни редове
- Често се използва заедно със **sort**
---
## sort и uniq - Примери

```bash
# uniq премахва само ПОСЛЕДОВАТЕЛНИТЕ повтарящи се редове.
uniq names.txt

# За да премахнем всички повторения, първо сортираме
cat history.txt | sort | uniq
```
---
## cut

- Позволява да оставим само част от изхода
- "-d" - разделяме изхода на колони
- "-f" - избираме кои колони да оставим
---
## cut - Примери

```bash
# Разделя всеки ред по ":" и оставя само 1-вата колона (потребителските имена)
cut -d: -f1 /etc/passwd

# Оставя 1-вата и 3-тата колона (потребителско име и UID)
cut -d: -f1,3 /etc/passwd

# Оставя колоните от 1-вата до 3-тата включително
# (потребителско име, парола (x) и UID)
cut -d: -f1-3 /etc/passwd

# Взима 7-мата колона (shell-а на всеки потребител), сортира,
# и с "uniq -c" брои колко потребители използват всеки shell
cat /etc/passwd | cut -d: -f7 | sort | uniq -c
```
---
## wc

- Показва колко редове/думи/символи има в един файл/вход
- "-l" - показва редове
- "-w" - показва думи
- "-c" - показва символи
---

## wc - Примери

```bash
# Показва броя на редовете, думите и байтовете в /etc/passwd, както и името на файла
wc /etc/passwd

# Същото, но данните идват от стандартния вход (чрез пайп),
# затова името на файла не се показва
cat /etc/passwd | wc
```

# awk
---
## Какво е awk?

- Инструмент за обработка на текст, разделен на **колони**
- Всеки ред се разделя на **полета** — подобно на `cut`, но с възможност за условия и изчисления
- Цял език за програмиране — тук ще разгледаме само най-полезните възможности

```bash
awk 'условие { действие }' файл
```

- Действието се изпълнява за всеки ред, който изпълнява условието
- Без условие — действието се изпълнява за всеки ред
- Без действие — редът се извежда
---
## awk - Полета

| Запис      | Значение                                   |
| ---------- | ------------------------------------------ |
| `$1`, `$2` | първото, второто, ... поле                 |
| `$0`       | целият ред                                 |
| `$NF`      | последното поле                            |
| `NF`       | брой полета на текущия ред                 |
| `NR`       | номер на текущия ред                       |
| `-F ";"`   | разделител между полетата                  |

- Без `-F` полетата се разделят по **интервали** — внимавайте с данни като `Бай Ганьо;30;9.9`
---
## awk - Извеждане на полета

- Ще използваме файла `books.info` във формат `КНИГА;БРОЙ;ЦЕНА`

```txt
Тютюн;12;18.5
Бай Ганьо;30;9.9
Под игото;25;14.2
Железният светилник;8;16.0
```

```bash
# Само заглавията (същото като cut -d ";" -f 1)
awk -F ";" '{ print $1 }' books.info

# Заглавие и цена, разделени с интервал
awk -F ";" '{ print $1, $3 }' books.info

# Собствен текст между полетата
awk -F ":" '{ print $1 " използва " $7 }' /etc/passwd
```

- За разлика от `cut`, с `awk` можем да сменим реда на колоните: `{ print $3, $1 }`
---
## awk - Условия

- Сравнения: `==`, `!=`, `<`, `>`, `<=`, `>=`
- Логически оператори: `&&` (и), `||` (или), `!` (не)
- `~` — полето съвпада с регулярен израз

```bash
# Книгите с цена над 15
awk -F ";" '$3 > 15 { print $1 }' books.info

# Книгите с брой между 10 и 30
awk -F ";" '$2 >= 10 && $2 <= 30' books.info

# Книгите, чиито заглавия започват с Б
awk -F ";" '$1 ~ /^Б/' books.info

# Обикновените потребители в системата (UID >= 1000)
awk -F ":" '$3 >= 1000 { print $1 }' /etc/passwd
```
---
## awk - Номера на редове

```bash
# Вторият ред
awk 'NR == 2' books.info

# От 2-рия до 3-тия ред
awk 'NR >= 2 && NR <= 3' books.info

# Всеки ред с номер пред него
awk '{ print NR ": " $0 }' books.info
```
---
## awk - BEGIN и END

- `BEGIN { ... }` — изпълнява се **веднъж**, преди да бъде прочетен първият ред
- `END { ... }` — изпълнява се **веднъж**, след като всички редове са прочетени
- Използват се за обобщения — суми, броене, максимум/минимум

```bash
# Общ брой книги
awk -F ";" '{ sum += $2 } END { print sum }' books.info

# Средна цена
awk -F ";" '{ sum += $3 } END { print sum / NR }' books.info

# Брой редове (като wc -l)
awk 'END { print NR }' books.info
```
---
## awk - Минимум и максимум

- Пазим най-добрата стойност досега в променлива и я сменяме, когато намерим по-добра
- `NR == 1` — първият ред винаги е начална стойност

```bash
# Книгата с най-малко бройки
awk -F ";" 'NR == 1 || $2 < min { min = $2; name = $1 } END { print name }' books.info
Железният светилник

# Най-високата цена
awk -F ";" 'NR == 1 || $3 > max { max = $3 } END { print max }' books.info
18.5
```

- Същото може да се постигне и със `sort | head -n 1 | cut`
---
## awk и десетични числа

- `awk` винаги очаква **точка** за десетичен разделител, независимо от езиковите настройки на системата
- Затова при сравняване на цени `awk` е по-надежден от `sort -n` (вижте „sort - Десетични числа“)

```bash
awk -F ";" '$3 < 10' books.info
Бай Ганьо;30;9.9
```
---
## awk в пайп

- Подобно на останалите команди, `awk` може да чете от стандартния вход

```bash
# Имената и размерите на файловете от ls -l
ls -l | awk '{ print $9, $5 }'

# Процесите, използващи над 1% процесор
ps aux | awk '$3 > 1 { print $2, $11 }'

# Сортираме по цена и взимаме заглавието на първия ред
sort -t ";" -k 3,3 -n books.info | awk -F ";" 'NR == 1 { print $1 }'
```

# sed
---
## Какво е sed?

- **Stream editor** — редактира текст ред по ред, без да отваря редактор
- Чете файл или стандартния вход и извежда **променения** текст
- Оригиналният файл **не** се променя (освен с `-i`)
- Подробно разглеждане — в урока „Работа с данни - Част 2“

```bash
sed 'команда' файл
```
---
## sed - Заместване

- `s/старо/ново/` — замества **първото** срещане на всеки ред
- `s/старо/ново/g` — замества **всички** срещания на всеки ред
- `старо` е регулярен израз

```bash
# Сменя разделителя ";" с " | " за по-четим изход
sed 's/;/ | /g' books.info
Тютюн | 12 | 18.5
...

# Сменя само първия ";" на всеки ред
sed 's/;/: /' books.info
Тютюн: 12;18.5
```
---
## sed - Извеждане на редове

- `-n` — не извежда редовете автоматично
- `p` — извежда реда
- Заедно извеждат **само** избраните редове

```bash
sed -n '2p' books.info        # вторият ред
sed -n '2,3p' books.info      # от 2-рия до 3-тия ред
sed -n '$p' books.info        # последният ред
sed -n '/^Б/p' books.info     # редовете, които започват с Б (като grep '^Б')
```
---
## sed - Изтриване на редове

- `d` — изтрива реда от изхода

```bash
sed '1d' students.csv         # без първия ред (заглавния ред на CSV файл)
sed '/^Под/d' books.info      # без редовете, започващи с "Под"
sed '/^$/d' file.txt          # без празните редове
sed '/^#/d' config.txt        # без коментарите
```
---
## sed -i - Промяна на файла

- `-i` — записва промените директно във файла, вместо да ги извежда
- **Внимание:** промяната е необратима — първо пробвайте командата без `-i`
- `-i.bak` — запазва копие на оригинала с разширение `.bak`

```bash
sed -i 's/Ганьо/Ганю/' books.info
sed -i.bak '/^$/d' file.txt   # file.txt е променен, file.txt.bak е оригиналът
```
---
## sed - Хващане на части от реда

- `-E` — разширени регулярни изрази (като `grep -E`)
- Частите в `( )` се използват при заместването с `\1`, `\2`, ...

```bash
# Извежда първите две полета в обратен ред, в нов формат
sed -E 's/^([^;]*);([^;]*);.*/\2 бр. - \1/' books.info
12 бр. - Тютюн
30 бр. - Бай Ганьо
...
```

- `[^;]*` — произволен брой символи, различни от `;` — т.е. едно поле
---
## Кога cut, awk или sed?

| Задача                                    | Команда |
| ----------------------------------------- | ------- |
| Извличане на колони                       | `cut`   |
| Колони в различен ред, условия, изчисления| `awk`   |
| Заместване на текст, изтриване на редове  | `sed`   |
| Търсене на редове по шаблон               | `grep`  |
