# Работа с данни

---
## Всичко е файл

- Философия за дизайна на Linux операционната система
- Всички системни ресурси, се третират като файлове, включително:
    - файлове и директории
    - устройства
    - процеси
---
## Програми

- Пазят се като изпълними файлове
- `/bin` - основни системни команди (cat, mv, ...)
- `/usr/bin` - незадължителни потребителски команди (g++, mysql, vscode)
- В модерни системи директориите често изпълняват една и съща цел
---
## Устройства

- Устройства като дискове, клавиатури и мишки се третират като специални файлове, които се пазят в папката `\dev`
- `\dev\sda` - дискът
- `\dev\ttyS0` - първият сериен порт
- `\dev\usb` - съдържа usb устройства
---
## Процеси

- Процесите се пазят като файлове в директорията `/proc/`
- Всеки процес получава директория (напр. процес с PID 1234 получава директория `/proc/1234`)
---
## Конфигурация

- Системните настройки се пазят в файлове
- `/etc` - пази конфигурацията за системата
- `/sys` - пази конфигурацията за ядрото
---
# Команди за работа с данни
---
## cat

- Показва съдържанието на файл

```bash
cat /etc/passwd
```
---
## head

- Показва началото на файл (По подразбиране първите 10 реда)

```bash
head /etc/passwd
```
---
## head -n

- Позволява ни да поясним колко редове искаме да видим

```bash
head -n 7 /etc/passwd # първите 7 реда
head -n -7 /etc/passwd # премахва последните 7 реда
```
---
## head -c

- Показва първите байтове на файл

```bash
head -c 7 /etc/passwd # първите 7 байта
```
---
## tail

- Показва краят на файл (По подразбиране последните 10 реда)

```bash
tail /etc/passwd
```
---
## tail -n

- Позволява ни да поясним колко редове искаме да видим

```bash
tail -n 7 /etc/passwd # последните 7 реда
tail -n +7 /etc/passwd # От 7-ят ред до края
```
---
## Пайпове - "|"

- Позволява ни да комбинираме команди
- Взима изходът на една команда и го превръща във вход на друга команда

```bash
command1 | command2 | command3 | ...
```
---
## Пайп - Пример

- Искаме да принтираме 5-ят до 10-ят ред на "/etc/passwd"

```bash
head -n 10 /etc/passwd | tail -n 5
```

- `tail` **не** получава име на файл — чете от stdin, т.е. от изхода на `head`
- Ако напишем `tail -n 5 /etc/passwd`, `tail` ще игнорира пайпа и ще прочете целия файл
---
## sort

- Позволява ни сортираме съдържание на стандартният вход **или** на подаден файл или файлове
---
```bash
sort /etc/passwd
cat /etc/passwd | sort
```
---
## sort - Опции

- "-n" - сортираме числово
- "-r" - сортираме в низходящ ред
- "-k" - сортираме по ключ
- "-t" - определяме разделител
- "-u" - премахва повтарящите се редове
---
## sort - Примери

```bash
# Сортира числата от numbers.txt числово (1, 38, 45, 123, 2000).
# Без -n сортирането е текстово и "123" би било преди "38".
sort -n numbers.txt

# Сортира числово, но в низходящ ред (2000, 123, 45, 38, 1)
sort -rn numbers.txt

# Сортира изхода на "ls -l" по 8-мата колона (час/година на последна промяна).
# Колоните са разделени с интервали: права, връзки, собственик, група,
# размер, месец, ден, час/година, име
ls -l | sort -k 8

# Сортира файловете по размер (5-тата колона), числово
ls -l | sort -nk 5

# Колоните в /etc/passwd са разделени с ":", затова задаваме разделител с -t.
# Сортираме числово по 4-тата колона (GID - номер на основната група)
cat /etc/passwd | sort -t ":" -nk 4
```
---
## sort -k - Начало и край на ключа

- `-k 2` означава „от 2-рата колона **до края на реда**“
- `-k 2,2` означава „**само** 2-рата колона“
- При текстово сортиране разликата има значение, затова е добре винаги да задаваме и края

```bash
# Сортира само по 2-рата колона (име), разделител ";"
sort -t ";" -k 2,2 data.info

# Сортира числово по 3-тата колона, в низходящ ред
sort -t ";" -k 3,3 -nr data.info
```
---
## sort - Десетични числа

- `sort -n` разпознава десетичния разделител според **езиковите настройки** (locale) на системата
- При български настройки (`bg_BG`) десетичният разделител е **запетая**, затова `2.5` се чете като `2`
- Проверка: `locale | grep LC_NUMERIC`
- Решение — задаваме „неутрален“ locale само за командата:

```bash
LC_ALL=C sort -t ";" -k 3,3 -n books.info
```
---
## Пример - Комбиниране на команди

- Файл `books.info` във формат `КНИГА;БРОЙ;ЦЕНА`:

```txt
Тютюн;12;18.5
Бай Ганьо;30;9.9
Под игото;25;14.2
Железният светилник;8;16.0
```

```bash
# Само заглавията, по азбучен ред
cut -d ";" -f 1 books.info | sort

# Заглавието на най-скъпата книга, записано във файл
sort -t ";" -k 3,3 -nr books.info | head -n 1 | cut -d ";" -f 1 > most_expensive

# Последните 2 реда от файла, сортирани по брой
tail -n 2 books.info | sort -t ";" -k 2,2 -n
```

- Редът на командите има значение: `tail | sort` взима последните редове **от файла** и тогава ги сортира, а `sort | tail` взима последните редове **след** сортирането
---
## uniq

- Премахва повтарящите се последователни редове
- Често се използва заедно със **sort**
---
## sort и uniq - Примери

```bash
# uniq премахва само ПОСЛЕДОВАТЕЛНИТЕ повтарящи се редове.
uniq names.txt

# За да премахнем всички повторения, първо сортираме
cat history.txt | sort | uniq
```
---
## cut

- Позволява да оставим само част от изхода
- "-d" - разделяме изхода на колони
- "-f" - избираме кои колони да оставим
---
## cut - Примери

```bash
# Разделя всеки ред по ":" и оставя само 1-вата колона (потребителските имена)
cut -d: -f1 /etc/passwd

# Оставя 1-вата и 3-тата колона (потребителско име и UID)
cut -d: -f1,3 /etc/passwd

# Оставя колоните от 1-вата до 3-тата включително
# (потребителско име, парола (x) и UID)
cut -d: -f1-3 /etc/passwd

# Взима 7-мата колона (shell-а на всеки потребител), сортира,
# и с "uniq -c" брои колко потребители използват всеки shell
cat /etc/passwd | cut -d: -f7 | sort | uniq -c
```
---
## wc

- Показва колко редове/думи/символи има в един файл/вход
- "-l" - показва редове
- "-w" - показва думи
- "-c" - показва символи
---

## wc - Примери

```bash
# Показва броя на редовете, думите и байтовете в /etc/passwd, както и името на файла
wc /etc/passwd

# Същото, но данните идват от стандартния вход (чрез пайп),
# затова името на файла не се показва
cat /etc/passwd | wc
```
