## Навигация

---
### pwd

- **Print Working Directory**
- Показва пълния път до текущата директория

```bash
# Показва пълния път до текущата директория
$ pwd
/home/user/Documents
```

---
### whoami

- Показва потребителското име на текущия потребител

```bash
# Показва името на текущия потребител
$ whoami
user
```

---
### ls

- **List** — показва съдържанието на директория
- Основни флагове:
    - `-l` — подробен формат
    - `-a` — показва скрити файлове
    - `-h` — размери в четим формат

```bash
# Показва съдържанието на текущата директория
$ ls
Desktop  Documents  Downloads

# Показва съдържанието в подробен формат, включително скритите файлове
$ ls -la
drwxr-xr-x  2 user user 4096 Apr 20 10:00 Desktop
```

---
### cd

- **Change Directory** — смяна на текущата директория
- Специални пътища:
    - `.` — текущата директория
    - `..` — родителската директория
    - `~` — домашната директория

```bash
# Преминава в директорията на посочения абсолютен път
$ cd /home/user/Documents

# Преминава в родителската директория
$ cd ..

# Преминава в домашната директория
$ cd ~
```

## Работа с файлове и директории

---
### mkdir

- **Make Directory** — създава нова директория
- `-p` — създава и липсващи родителски директории

```bash
# Създава директория my_folder в текущата директория
$ mkdir my_folder

# Създава lab1 заедно с липсващите родителски директории projects и os
$ mkdir -p projects/os/lab1
```

---
### touch

- Създава нов празен файл
- Ако файлът съществува, обновява времето му на промяна

```bash
# Създава празен файл file.txt или обновява времето му на промяна, ако вече съществува
$ touch file.txt

# Създава два файла наведнъж
$ touch script.sh notes.md
```

---
### rm

- **Remove** — изтрива файлове и директории
- Основни флагове:
    - `-r` — рекурсивно (за директории)
    - `-f` — без потвърждение
- **Внимание:** операцията е необратима

```bash
# Изтрива файла file.txt
$ rm file.txt

# Изтрива директорията my_folder с цялото ѝ съдържание, без потвърждение
$ rm -rf my_folder
```

---
### cp

- **Copy** — копира файлове и директории
- `-r` — рекурсивно копиране на директории

```bash
# Копира file.txt в нов файл backup.txt
$ cp file.txt backup.txt

# Копира директорията folder с цялото ѝ съдържание във folder_backup
$ cp -r folder/ folder_backup/

# Копира няколко файла наведнъж в директорията backup/ (последният аргумент е целта)
$ cp file1.txt file2.txt notes.md backup/
```

---
### mv

- **Move** — премества или преименува файлове и директории

```bash
# Преименува old_name.txt на new_name.txt
$ mv old_name.txt new_name.txt

# Премества file.txt в директорията /home/user/Documents/
$ mv file.txt /home/user/Documents/

# Премества няколко файла наведнъж в директорията archive/
$ mv a.txt b.txt c.txt archive/
```

---
### Скрити файлове и директории

- В Linux файл или директория е **скрит(а)**, ако името започва с `.`
- Няма специален флаг за „скриване“ — достатъчно е да преименуваме с `mv`
- Скритите файлове се виждат само с `ls -a`

```bash
# Прави директорията DIR1 скрита
$ mv DIR1 .DIR1

$ ls
DIR2  DIR3
$ ls -a
.  ..  .DIR1  DIR2  DIR3
```

---
### Имена с интервали

- Интервалът разделя аргументите на командата
- Име с интервал трябва да се огради с кавички или интервалът да се екранира с `\`

```bash
# Създава ЕДНА директория с име "Summer Photos"
$ mkdir "Summer Photos"
$ mkdir Summer\ Photos

# Създава ДВЕ директории — Summer и Photos
$ mkdir Summer Photos
```

## Шаблони за имена (wildcards)

---
### Какво са wildcards?

- Специални символи, с които описваме **група от имена** на файлове
- **Shell-ът** заменя шаблона със списък от съвпадащите имена **преди** да стартира командата
- Работят с всяка команда — `ls`, `cp`, `mv`, `rm`, ...
- Наричат се още **globbing**

| Шаблон    | Значение                                      |
|-----------|-----------------------------------------------|
| `*`       | произволен брой произволни символи (и нула)   |
| `?`       | точно **един** произволен символ              |
| `[abc]`   | точно един символ от изброените               |
| `[a-z]`   | точно един символ от диапазона                |
| `[!abc]`  | точно един символ, който **не** е изброен     |

---
### Шаблонът `*`

```bash
# Всички .txt файлове в текущата директория
$ ls *.txt
file1.txt  notes.txt  summary.txt

# Всички файлове, които започват с strypes
$ ls strypes*
strypes_plan.pdf  strypes_summary.txt

# Всички файлове, които съдържат report в името си
$ ls *report*
project_report.docx  report1.docx
```

---
### Шаблонът `?`

- Всеки `?` отговаря на **точно един** символ
- Полезен, когато знаем **дължината** на част от името

```bash
# Файлове с разширение от точно 3 символа (.txt, .pdf, .doc)
$ ls *.???
file1.txt  file2.pdf  old.doc

# Файлове с разширение от точно 4 символа (.docx, .pptx, .xlsx)
$ ls *.????
project_report.docx  presentation.pptx

# note1.txt ... note9.txt, но не и note10.txt
$ ls note?.txt
```

---
### Шаблонът `[]`

```bash
# report1.docx, report2.docx и report3.docx
$ ls report[1-3].docx

# Файлове, започващи с главна буква
$ ls [A-Z]*

# Файлове, които НЕ завършват на цифра
$ ls *[!0-9]
```

---
### Wildcards с cp, mv и rm

```bash
# Копира всички .txt файлове в DIR1
$ cp *.txt DIR1/

# Копира .txt файловете от всички поддиректории на DIR в DIR1
$ cp DIR/*/*.txt DIR/DIR1/

# Премества всички .pdf файлове в DIR3
$ mv *.pdf DIR3/

# Изтрива всички файлове с 3-символно разширение в DIR3
$ rm DIR3/*.???
```

- **Внимание:** `rm *` изтрива всичко в текущата директория — проверете шаблона с `ls` преди да го подадете на `rm`

---
### Когато няма съвпадение

- Ако няма нито едно съвпадение, `bash` подава шаблона **буквално** на командата

```bash
$ ls *.mp3
ls: cannot access '*.mp3': No such file or directory
```

- `*` **не** съвпада със скрити файлове (започващи с `.`)

---
### Brace expansion — `{}`

- Генерира **списък от думи** — не проверява дали файловете съществуват
- Удобен за създаване на много файлове и директории наведнъж

```bash
# Създава note1.txt, note2.txt, ..., note5.txt
$ touch note{1..5}.txt

# Създава report1.docx, report2.docx, report3.docx
$ touch report{1..3}.docx

# Създава три поддиректории наведнъж
$ mkdir -p Romania/{Bucharest,Cluj,Constanta}

# Създава вложени директории наведнъж
$ mkdir -p Romania/Bucharest/{Sector1,Sector6}
```

- Между елементите **не** се слагат интервали: `{a,b}`, а не `{a, b}`

---
### Пример: създаване на структура

```bash
$ mkdir -p ProjectFiles/{Documents,TextFiles,Images}
$ touch ProjectFiles/Documents/report{1..3}.docx
$ touch ProjectFiles/TextFiles/note{1..5}.txt
$ touch ProjectFiles/Images/{logo.png,diagram.jpg,chart.png}

# Показва структурата като дърво (sudo apt install tree)
$ tree ProjectFiles
ProjectFiles
├── Documents
│   ├── report1.docx
│   ├── report2.docx
│   └── report3.docx
├── Images
│   ├── chart.png
│   ├── diagram.jpg
│   └── logo.png
└── TextFiles
    ├── note1.txt
    ...
```

---
### nano

- Прост текстов редактор в терминала
- Основни клавишни комбинации:
    - `Ctrl + O` — запазване
    - `Ctrl + X` — изход
    - `Ctrl + W` — търсене

```bash
# Отваря file.txt в редактора nano (ако файлът не съществува, ще бъде създаден при запазване)
$ nano file.txt
```

## Текстови команди

---
### echo

- Извежда текст или стойност на променлива на стандартния изход
- Може да се използва за запис във файл

```bash
# Извежда текста на стандартния изход
$ echo "Hello, World!"
Hello, World!

# Записва текста в os.txt, като презаписва съдържанието на файла
$ echo "Linux" > os.txt

# Добавя текста в края на os.txt, без да изтрива съществуващото съдържание
$ echo "Ubuntu" >> os.txt
```

---
### cat

- **Concatenate** — извежда съдържанието на един или повече файлове
- При няколко файла ги извежда последователно, един след друг
- `-n` — номерира редовете

```bash
# Извежда съдържанието на os.txt
$ cat os.txt
Linux
Ubuntu

# Извежда съдържанието на os.txt с номерирани редове
$ cat -n os.txt
     1	Linux
     2	Ubuntu
```

---
### wc

- **Word Count** — брои редове, думи и байтове във файл
- Основни флагове:
    - `-l` — само редове
    - `-w` — само думи
    - `-c` — само байтове

```bash
# Показва броя на редовете, думите и байтовете в os.txt
$ wc os.txt
 2  2 13 os.txt

# Показва само броя на редовете в os.txt
$ wc -l os.txt
2 os.txt
```
