## Какво е бекъп?

- Копие на данните, което се съхранява на отделно място
- Позволява възстановяване при загуба, повреда или случайно изтриване
- Критичен елемент от всяка система

---
## Стратегии за бекъп

---
### Пълен бекъп (Full Backup)

- Копира **всички** данни всеки път
- Лесно възстановяване — нужен е само един архив
- Бавен и заема много място

---
### Инкрементален бекъп (Incremental Backup)

- Копира само промените **от последния бекъп** (пълен или инкрементален)
- Бърз и пестелив откъм място
- Възстановяването изисква пълния бекъп + всички инкрементални

```
Пон: Full  →  Вт: +Δ1  →  Ср: +Δ2  →  Чет: +Δ3
```

---
### Диференциален бекъп (Differential Backup)

- Копира само промените **от последния пълен бекъп**
- Компромис между скорост и простота на възстановяване
- Нужни са само пълният бекъп + последният диференциален

```
Пон: Full  →  Вт: ΔA  →  Ср: ΔA+B  →  Чет: ΔA+B+C
```

---
### Правилото 3-2-1

- **3** копия на данните
- На **2** различни носителя
- **1** копие на отдалечено място (off-site)

## tar

- **Tape Archive** — архивиране на файлове и директории
- Може да комбинира компресия (gzip, bzip2, xz)

---
### Основни флагове

| Флаг | Описание                     |
|------|------------------------------|
| `-c` | Създаване на архив           |
| `-x` | Разархивиране                |
| `-t` | Списък на съдържанието       |
| `-r` | Добавяне на файлове в архив  |
| `-f` | Име на архивния файл         |
| `-v` | Verbose — показва прогреса   |
| `-z` | Компресия с gzip (.tar.gz)   |
| `-j` | Компресия с bzip2 (.tar.bz2) |
| `-C` | Смяна на директорията        |

- `-f` трябва да е **последен** в групата флагове, защото веднага след него стои името на архива: `-cvf archive.tar`, а не `-cfv archive.tar`

---
### Примери

```bash
# Създаване на архив
$ tar -cvf archive.tar /home/user/documents

# Създаване с gzip компресия
$ tar -czvf archive.tar.gz /home/user/documents

# Разархивиране
$ tar -xzvf archive.tar.gz

# Разархивиране в конкретна директория
$ tar -xzvf archive.tar.gz -C /tmp/restore
```

- Директорията след `-C` трябва да **съществува** — ако не, първо я създаваме с `mkdir -p`

---
### Пътища в архива

- `tar` запазва пътищата **такива, каквито сме ги подали**
- Водещият `/` се премахва, за да не презапише системни файлове при разархивиране

```bash
$ tar -cvf docs.tar ~/Documents
tar: Removing leading `/' from member names
$ tar -tf docs.tar
home/user/Documents/
home/user/Documents/report.docx
```

- С `-C` влизаме в директорията преди архивиране — архивът съдържа само нейното съдържание

```bash
$ tar -cvf docs.tar -C ~/Documents .
$ tar -tf docs.tar
./
./report.docx
```

---
### Разглеждане на архив (-t)

```bash
# Списък на файловете и директориите в архива
$ tar -tf archive.tar

# Подробен списък — права, собственик, размер, дата
$ tar -tvf archive.tar
-rw-r--r-- user/user  10240 2026-11-10 12:00 Documents/report.docx

# Само файловете, които съдържат "report" в името си
$ tar -tf archive.tar | grep 'report'

# Само файловете (без директориите) — имената на директориите завършват на /
$ tar -tf archive.tar | grep -v '/$'
```

---
### Добавяне към архив (-r)

- Добавя файлове в **края** на съществуващ архив
- Ако архивът не съществува, се създава
- Работи **само** с некомпресирани `.tar` архиви

```bash
# Добавя всички .sh файлове от текущата директория
$ tar -rvf scripts.tar *.sh

# Проверка
$ tar -tf scripts.tar
```

---
### Изключване на файлове (--exclude)

- Ако създаваме архив на директория, в която се намира и самият архив, `tar` ще се опита да архивира и него
- С `--exclude` пропускаме файлове, които съвпадат с шаблон

```bash
# Архив на home директорията, без самия архив и без кеша
$ cd ~
$ tar -cvf home_backup.tar --exclude=home_backup.tar --exclude=.cache .
```

- Друг вариант е архивът да се създаде **извън** архивираната директория, напр. в `/tmp`

## rsync

- **Remote Sync** — синхронизиране на файлове локално или отдалечено
- Копира само **разликите** — бърз при повтарящи се бекъпи
- Поддържа SSH за сигурен трансфер

---
### Основни флагове

| Флаг | Описание                                      |
|------|-----------------------------------------------|
| `-a` | Archive mode (рекурсивно, запазва права)      |
| `-v` | Verbose                                       |
| `-z` | Компресия при трансфер                        |
| `-P` | Показва прогреса, продължава при прекъсване   |
| `--delete` | Изтрива файлове, липсващи в източника  |

---
### Примери

```bash
# Локален бекъп
$ rsync -av /home/user/documents/ /backup/documents/

# Отдалечен бекъп през SSH
$ rsync -avz /home/user/documents/ user@server:/backup/documents/

# Синхронизиране с изтриване на излишни файлове
$ rsync -av --delete /source/ /destination/
```

---
## tar vs rsync

| Характеристика     | tar                  | rsync                      |
|--------------------|----------------------|----------------------------|
| Резултат           | Един архивен файл    | Огледало на директория     |
| Инкрементален      | С допълнителни опции | По подразбиране            |
| Отдалечен трансфер | Ръчно (scp/ssh)      | Вградена поддръжка         |
| Приложение         | Снапшоти, архиви     | Редовна синхронизация      |
