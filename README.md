# Операционни системи

Материали от курса по Операционни системи

Курсът разглежда основните принципи на операционните системи (процеси, права за достъп, файлова система) с практически фокус върху Linux — работа от команден ред, автоматизация с shell скриптове, мрежи, виртуализация и контейнеризация, както и основи на сигурността.

## Конспект

### Първи срок (теми 1–15)

1. Въведение
2. Функции на операционната система
3. Компоненти на операционната система
4. Linux
5. Основни команди
6. Управление на пакети
7. Права за достъп (Permissions)
8. Работа с данни
9. Регулярни изрази
10. Процеси
11. Архивиране (Backup)
12. Демони и търсене (Daemons, Searching)
13. Работна среда (Environment)
14. Обобщение на курсовата работа
15. Защита на курсовата работа

### Втори срок (теми 16–26)

16. Връзки във файловата система (Links)
17. Shell скриптове
18. Cron задачи
19. Логване (Logging)
20. Устройства (Devices)
21. Мрежи (Networking)
22. Виртуализация
23. Контейнеризация
24. Docker Compose
25. SSH
26. Сигурност
